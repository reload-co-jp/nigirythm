受信箱にたまる迷惑メールの「スパム」と、世界中で使われているプログラミング言語「Python」。一方は嫌われ者で、もう一方は人気者だ。共通点はなさそうに見えるこの二つの言葉は、どちらもイギリスの同じコメディ番組にたどり着く。

## 缶詰から迷惑メールへ

SPAM は、米国ホーメルフーズが販売する加工肉の缶詰の名前である<Ref id="kb-spam" />。ブランド名そのものが何を意味するのかについて、ホーメルの公式FAQは「長く憶測の対象になってきた」と書いている<Ref id="spam-faq" />。名前の由来からして、すでに諸説ある言葉なのだ。

その缶詰の名前が、なぜ迷惑メールを指すようになったのか。IT用語辞典は、イギリスのコメディグループ、モンティ・パイソンの番組にスパムが大量に登場する場面があり、その連想から、ネットワークを通じて大量のメッセージを繰り返し送る迷惑行為を「スパム」と呼ぶようになった「とされる」と説明している<Ref id="kb-spam" />。

辞典自身が「とされる」と書いている点は見逃せない。商品名が迷惑行為の名前になった経緯は広く知られているが、最初に誰がその意味で使ったのかまでは、本サイトではまだ確認できていない。

## 蛇ではない Python

Python の場合は、由来がはっきりしている。公式ドキュメントのFAQには「なぜ Python という名前なのか」という項目がある。作者のグイド・ヴァンロッサムは、言語の実装を始めた頃、BBCのコメディ番組「Monty Python's Flying Circus」の台本を読んでいた。そして、短く、独特で、少し謎めいた名前が必要だと考え、Python と名付けたという<Ref id="python-faq" />。

同じFAQには「Monty Python's Flying Circus を好きでなければいけないのか」という質問まであり、答えは「いいえ。でも好きだと役に立ちます :)」だ<Ref id="python-faq" />。

## もうひとつのパイソン

ややこしいのは、英語の python がもともと蛇を指す言葉だということだ。辞典を引くと、パイソンはニシキヘビの別名であり、ギリシア神話でアポロが退治した巨大な蛇の名でもある。そして三つ目の語義として、スクリプト言語の名前が載っている<Ref id="kb-python" />。

言語のロゴには蛇が描かれているため、名前も蛇から来たと思われがちだ。しかし公式の説明に従えば、言語名と蛇との関係は、コメディ集団の名前を経由した間接的なものにすぎない。同じ表記の背後に、別の由来が隠れている例である。

## 二つの言葉、ひとつの番組

スパムは「繰り返し」の連想から生まれたとされる比喩で、Python は作者が意図して選んだ固有名詞だ。成り立ちはまったく違う。それでも、一つのコメディ番組が、のちのインターネットとプログラミングの言葉に二つも名前を残したことになる。

言葉の由来をたどると、思いがけない場所でつながることがある。ただし、つながりがあると言えるのは、それを示す資料があるときだけだ。
